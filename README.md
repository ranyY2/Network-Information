Open-source Python network toolkit for system diagnostics, network analysis, device discovery, traffic monitoring, and security research on Windows and Linux.# NetKit

NetKit is an open-source network diagnostics and security research toolkit written in Python, with additional PowerShell support.

The project provides tools for exploring network configurations, inspecting local devices, monitoring network traffic, and experimenting with network security techniques in authorized environments.

## Features

**Windows Network Diagnostics**
- Network adapter and connection information
- IPv4 and IPv6 configuration details
- DNS, DHCP, gateway, and MAC address information
- Wi-Fi SSID identification
- Local ARP cache inspection
- Graphical interface using Dear PyGui
- Command-line interface

**Linux Network Security Toolkit**
- MAC address modification and restoration
- Tor proxy configuration
- Local network device discovery
- HTTP traffic inspection
- Basic network host discovery
- Experimental ARP spoofing, Wi-Fi deauthentication, and UDP traffic generation functionality

## Technologies

- Python
- PowerShell
- Scapy
- Dear PyGui
- Windows Networking APIs
- Linux Networking Utilities

## Disclaimer

This project is intended for educational purposes, network diagnostics, and authorized security research only. Security testing functionality should only be used on systems and networks you own or have explicit permission to test.
